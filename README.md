# Nishant Kumar — Portfolio Website

A personal portfolio website built with **React** and **styled-components**, showcasing my work experience, projects, and skills.

**Live:** [nkofficial07.github.io/Portfolio-Website](https://nkofficial07.github.io/Portfolio-Website/)

---

## Sections

- **Home** — Hero section with animated role titles and company tag
- **About** — Professional bio with photo
- **Experience** — Work history at Siemens EDA and Turtlemint
- **Projects** — Featured project showcase with live/code links
- **Technologies** — Tech stack icons
- **Playground** — Practice projects and birthday countdown
- **Contact** — Email, phone, and social links

## Tech Stack

- React 17 with code splitting (`React.lazy` / `Suspense`)
- styled-components for component-level styling
- react-scroll for smooth navigation
- react-parallax for parallax sections
- react-icons for iconography
- IntersectionObserver-based scroll-reveal animations
- Deployed via GitHub Pages

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm start

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## Features

- Responsive design for mobile and desktop
- Scroll-reveal animations on all sections
- Staggered hero entrance animations
- Frosted glass sticky navbar with backdrop blur
- Downloadable resume from navbar
- Grayscale-to-color tech icon hover effects
- Project card lift and shadow hover transitions
- Error boundary for graceful error handling
- SEO meta tags and accessibility support (`prefers-reduced-motion`)
